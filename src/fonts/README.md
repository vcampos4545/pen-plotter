# Fonts

Bundled with the Text tool. Nothing is fetched from the network at run time.

## Single-stroke: Hershey fonts (`hershey/`)

`futural.jhf` (Hershey Sans), `rowmand.jhf` (Sans Bold), `timesr.jhf` (Serif),
`timesi.jhf` (Serif Italic), `scripts.jhf` (Script), `cursive.jhf` (Cursive) and
`gothiceng.jhf` (Gothic), unchanged from Kamal Mostafa's
[hershey-fonts](https://github.com/kamalmostafa/hershey-fonts) distribution of the
Usenet release.

The Hershey Fonts were originally created by Dr. A. V. Hershey while working at the
U. S. National Bureau of Standards. The format of the Font data in this distribution
was originally created by James Hurt, Cognition, Inc., 900 Technology Park Drive,
Billerica, MA 01821. The full use terms that come with the data are in
[`hershey/hershey.txt`](hershey/hershey.txt): anyone may use it for any purpose as
long as these acknowledgements go with it.
